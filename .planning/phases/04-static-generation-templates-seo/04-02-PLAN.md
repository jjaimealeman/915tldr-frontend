## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| D1-derived text → JSON-LD `<script>` | Untrusted AI-generated titles/summaries enter a script context |
| D1-derived text → HTML attributes/text | Card titles, source names, category names |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | Tampering | structured-data.ts `toSafeJsonLd` | high | mitigate | Escape `<`, `>`, `&`, U+2028, U+2029 after `JSON.stringify`; unit test proves a `</script>` headline cannot close the element and round-trips via `JSON.parse` |
| T-04-06 | Tampering | ArticleCard/Base text and attributes | medium | mitigate | Astro default escaping only; `set:html` is used solely for the `toSafeJsonLd` output |
| T-04-07 | Information Disclosure | build-info.ts git calls | low | accept | Only a commit hash and date are exposed — both already public by design (OPS-05/06) |
| T-04-08 | Spoofing | canonical link | low | mitigate | Canonical built from `Astro.site` + a path argument, never from request data (all pages are prerendered) |
</threat_model>
