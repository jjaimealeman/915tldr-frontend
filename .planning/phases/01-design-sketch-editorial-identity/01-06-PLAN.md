**Markup contract (from 01-02; follow it exactly — 01-08 and 01-09 test against it):**
- `body[data-page]`.
- Skip link `[data-skip-link]` → `#main`; `main#main` carries `tabindex="-1"`.
- `nav[aria-label="Sections"]` holds eight `a[data-nav-category][data-category]` in canonical order, each containing a `[data-stripe]` span. The current category's link has `aria-current="page"`.
- Toggle: `button[data-theme-toggle][hidden][aria-pressed]`.
- Lead: `[data-lead][data-lead-variant][data-uuid][data-category]`.
- Grid: `section[data-grid]` holding `article[data-card][data-uuid][data-category]`, each with `[data-stripe]`, `[data-category-name]`, an `h3` headline, `[data-summary]` and `[data-byline]` (containing `[data-source]` and a `time[datetime]`).
- Stress cards carry `data-stress="<case id>"`. Spanish cards add `lang="es"` and `data-variant="es-real"` or `"es-synthetic"`.
- Elements the Spanish spec injects into carry `data-i18n="<component id>"`.
- Colour blocks: `[data-block][data-category]`.
- Exactly one script: the head theme script from 01-02, byte-identical on every page.

**Rules for uncategorized and missing data (probe resolutions tested in 01-08 and 01-09):**
- Uncategorized card: `data-category="none"`. Its stripe resolves to `--cat-none`, and it has **no** `[data-category-name]` element — never an empty one.
- No-summary card: it has **no** `[data-summary]` element and no min-height reserving the space. If `stress-set.json` marks `no-summary` as absent, draw the state from the `shortest-headline` row with its summary left out. Mark it `data-stress="no-summary"` and add an HTML comment saying the summary was left out to draw the Phase 2 state.
- Junk-image row: rendered with no `img` at all (Phase 7 filters these). Record the rejected URL in an HTML comment.

**Images (planner resolution of CONTEXT open item 6):**
- Use real source image URLs from the fixture, hotlinked, as the v1 site does.
- Each image sits in a fixed 3:2 frame with `width="1200" height="800"` attributes, `object-fit: cover`, and `alt=""`: it is a thumbnail duplicating the linked headline.
- Tests abort third-party requests, so layout must hold with the image missing. The frame's background is `var(--rule)`, never a broken-image look. Component CSS never uses colour literals; every colour is a token (the 01-05 gate enforces this).
- Card thumbnails use `loading="lazy"`. The category lead uses `loading="eager"` and `fetchpriority="high"`.

**Times:** AP style, for example "Sept. 16, 8:02 a.m.". The `time` element's `datetime` is ISO 8601 with offset.

**Escaping:** escape `&`, `<` and `>` in all corpus text.
