**Current interface (from 01-02, extended here, never renamed):** `extractRegion(css, name)`, `parseTokenRules(regionText)` → `{ light, dark }`, `resolveTheme(rules, theme)`, `toSrgb(value)`. CLI: `node design/scripts/check-contrast.mjs [--css path] [--out path]`, exit 0 or 1. This plan adds a `--json` flag, which prints the machine result to stdout, and the export `CANONICAL_SLUGS = ['crime','politics','sports','business','education','community','health','weather']`.

**Rule table the hardened gate enforces:**

| Group | Check | Threshold | Themes |
|---|---|---|---|
| Neutrals | ink vs paper; ink-muted vs paper; link vs paper | ≥ 4.5 | light, dark |
| Neutrals | cat-none vs paper | ≥ 3 | light, dark |
| Ramp row 1 | every `--cat-<slug>-vivid-light` vs light paper (WCAG 1.4.11) | ≥ 3, worst hue reported | light |
| Ramp row 2 | light and dark `--block-ink` vs every `--cat-<slug>-block` | ≥ 4.5, worst hue reported | both |
| Ramp row 3 | every `--cat-<slug>-vivid-dark` vs dark paper | ≥ 3, worst hue reported | dark |
| Focus | focus-ring vs paper | ≥ 3 | light, dark |
| Focus | focus-ring-on-block vs every block | ≥ 3 | light, dark |
| Structure | the required manifest is present: the neutrals above, `--block-ink`, `--focus-ring-on-block`, and for each canonical slug `--hue-<slug>`, three stop literals and the alias; the six `--stop-*` numbers | present and resolvable | both |
| Structure | categories found equal `CANONICAL_SLUGS` in order | exact | — |
| D-02 | each stop literal's L equals `--stop-<stop>-l` (±0.0005), its C is ≤ `--stop-<stop>-c` + 0.0005, and its hue equals `--hue-<slug>` (±0.05) | exact | — |
| Gamut | every colour token is `displayable` in sRGB | required | both |
| Coverage | every colour-valued declaration in the tokens region is covered, or is in `EXEMPT` with a reason. A declaration is covered when a pair uses it directly, when it is a pure `var()` alias of a covered token (for example `--cat-<slug>`), or when a pair's token resolves through it (for example `--rule-strong` behind `--cat-none`) | required | both |
| DSGN-04 | minimum pairwise `differenceEuclidean('oklab')` at each stop | ≥ 0.05 | — |
| C-01 neutrals | `--paper`, `--ink`, `--ink-muted`, `--rule`, `--rule-strong`, `--block-ink`: if the OKLCH hue lies in 35–110° then C ≤ 0.006 | required | both |
| C-01 review | block stop hue in 40–100° | warning only | — |
| Literals | outside the fonts and tokens regions, no declaration value in style.css (selectors are ignored, so `#main` is fine) contains a colour literal (`#` hex, `rgb(`, `rgba(`, `hsl(`, `hsla(`, `oklch(`, `oklab(`, `lab(`, `lch(`, `color(`, `color-mix(`); every component colour is a `var()` of a checked token | required | — |

`EXEMPT` starts with exactly two entries, each with its reason: `--rule` ("decorative divider; carries no information") and `--link-underline` ("currentColor; inherits the link colour already checked").

Known WCAG reference values used in the tests: `#767676` on `#FFFFFF` is 4.54:1 (passes 4.5); `#777777` on `#FFFFFF` is 4.48:1 (fails 4.5).
