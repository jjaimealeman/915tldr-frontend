**Research corrections applied in this plan (verified during planning, 2026-09-16):**

The capsize metrics for `tinos` are identical to `timesNewRoman` (ascent 1825, descent -443, lineGap 87, xWidthAvg 832, unitsPerEm 2048), and Liberation Serif 2.x derives from Tinos, so the Times-metric fallback face can list all three local names.

**style.css layout contract (fixed here; Phase 3 copies it):** the file begins with three marked regions, in this order, then component CSS.
- `/* fonts:start */ … /* fonts:end */` — generated by `build-fonts.mjs`. It holds the primary and fallback @font-face rules and one `:root` rule declaring `--font-display` and `--font-body`.
- `/* tokens:start */ … /* tokens:end */` — exactly two rules. The first has selector `:root` (light theme and all shared tokens); the second has selector `[data-theme="dark"]` (dark overrides only). Inside them sit one declaration per line and comment lines, nothing else. The `:root` rule contains a `/* palette:start */ … /* palette:end */` sub-region; the dark rule contains `/* palette-dark:start */ … /* palette-dark:end */`. 01-03's generator owns both sub-regions.
- Palette sub-region line format (one line each, per category slug, in canonical order): `--hue-<slug>: <deg>;`, `--cat-<slug>-vivid-light: oklch(<L> <C> <deg>);`, `--cat-<slug>-block: oklch(<L> <C> <deg>);`, `--cat-<slug>-vivid-dark: oklch(<L> <C> <deg>);`, `--cat-<slug>: var(--cat-<slug>-vivid-light);`.
