**Facts this plan relies on (verified during planning, 2026-09-16):**
- The layout-shift entry type is unsupported in every Safari release (caniuse, through 27.1). 01-02's geometry instrument covers WebKit.
- WebKit bug 219735 (ascent/descent/line-gap overrides) was resolved in trunk on 2026-08-05 but is not in any shipped Safari. Playwright's WebKit tracks trunk, so it may honour the overrides even though Safari users do not get them. That is why the size-adjust-only variant exists.
- Fallback faces installed on this machine: Liberation Serif and Noto Serif. The Playwright Docker image ships Liberation fonts. Georgia is not installed on either, so the Georgia fallback face — the one macOS, iOS and Windows readers get — can be checked only arithmetically, via capsize. The report must say so.
- Re-check the WebKit status immediately before running (RESEARCH says it is in flux): fetch https://caniuse.com/mdn-css_at-rules_font-face_ascent-override and record the result in font-cls.md.
