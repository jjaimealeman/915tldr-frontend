`server/utils/source-fetch.ts` exports two things.

`isAllowedSourceUrl(url: string, allowedHosts: Set<string>): boolean` is a pure predicate. It
parses the URL, requires the `https:` protocol, requires `hostname` to be present in
`allowedHosts` by exact full-hostname equality (never a suffix test, never a substring test),
and rejects any hostname that is a literal private, loopback, link-local or unique-local
address form. An empty allowlist refuses everything; it never defaults open.

`fetchSourcePage(url, { allowedHosts, signal })` returns a discriminated result, not a bare
string: `{ ok: true, html, finalUrl }` or `{ ok: false, reason }`, where `reason` is one of a
small named set — `not-allowed`, `robots-disallowed`, `timeout`, `http-error`,
`network-error`, `redirect-escaped-allowlist`. It never throws for an expected failure, because
the caller's fallback logic branches on `reason` and a thrown error would lose the distinction
between "this source blocked us" and "this one page is missing".

Behaviour it implements:
  - The allowlist check runs before the request and again on every redirect hop. Cap redirects
    at a small named constant; a redirect leaving the allowlist yields
    `redirect-escaped-allowlist`.
  - A `User-Agent` naming the project and carrying a contact URL, declared as a module-top
    constant so it is editable in one place.
  - A per-host minimum interval between requests, as a module-top constant. Research assumption
    A4 suggests a 10 to 15 second range; pick a value in that range, name it, and record in a
    comment that the figure is a synthesised recommendation rather than a published policy of
    any of the three outlets. Requests to different hosts are not serialised against each other.
  - Robots handling: fetch and cache each host's robots file for the life of the Worker
    invocation, and refuse a path its directives disallow for this User-Agent. A robots file
    that is missing or errors is treated as permissive; one that disallows is honoured.
  - A request timeout as a module-top constant, implemented with an `AbortController` so a slow
    newsroom cannot consume the cron invocation's CPU budget.
  - Exactly one retry with a backoff on a network error or a 5xx result. Not two. A retry storm
    against a struggling newsroom is the opposite of the politeness this module exists for.

Use the `[Source Fetch]` bracketed log prefix, matching the repo's unbroken convention.
