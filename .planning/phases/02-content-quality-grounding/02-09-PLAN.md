<objective>
Build the free half of the OPS-11 gate: sweep the whole corpus with checks that cost nothing,
union the outage-window rows, project what the judge stage and the Batch re-processing would
cost, and write a report — calling nothing paid.

Purpose: D-15 makes the $1 gate structural rather than procedural. A `--confirm` flag is one
flag away from being bypassed, including by an agent, and an interactive prompt does not survive
cron or a subagent. So the dry run computes and writes; a separate command executes and refuses
to start without pointing at a specific report. This plan is the first half. It also has to be
honest about a cost the phase creates: judging the deterministically-flagged subset is itself a
paid operation, so its projection belongs in the same report the owner approves.

Output: a token-and-cost estimator validated against real billed usage, the sweep script, and a
report carrying the exact affected row count, both projected costs, a per-source breakdown and a
corpus fingerprint.
