<objective>
Expand the tracer's minimum-viable grounding gate into the full detection cascade behind the
same `checkGrounding` signature: deterministic checks that cost nothing, verbatim-overlap
scoring, and a claim-level judge whose cited evidence is verified in code rather than trusted.

Purpose: CONT-04 asks for *any* claim not traceable to its source. A phrase lexicon would catch
the published fabrication's vocabulary but not the general case — a fabrication phrased without
advisory words passes a lexicon clean, and that blind spot is exactly why D-08 chose a hybrid.
Equally, a single-pass "does this summary match this source" judge reads a sentence carrying one
true fact and one invented claim as mostly accurate, which makes the review queue useless
because it cannot say *which* claim is wrong.

Output: a shared text-metrics module so nothing in the pipeline disagrees about what length
means, verbatim-overlap scoring for CONT-07, and a claim-level judge with span re-verification
and title coverage.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scraped source text + model-generated summary → judge prompt | Both sides of the comparison are untrusted text entering a prompt whose output gates publication |
| judge response → publication decision | Model output decides whether an article publishes; its self-reported evidence is the thing most worth distrusting |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-02 | Tampering | Prompt injection into the judge via scraped source text | high | mitigate | Source and summary go into labelled, delimited sections and are never spliced into the system prompt; the judge's output is parsed as strict JSON against a known shape; a shape mismatch flags rather than passes |
| T-02-21 | Tampering | A judge that fabricates its own supporting citation | high | mitigate | Every cited `sourceSpan` on a supported claim is re-verified by containment against the normalised source in code; an absent span downgrades the claim to unsupported |
| T-02-22 | Denial of Service (to correctness) | A failing judge silently green-lighting publication | high | mitigate | Every failure path — throw, timeout, unparseable JSON, missing claims array — returns `flagged: true` carrying the deterministic verdict; asserted by dedicated tests |
| T-02-23 | Denial of Service | Quadratic longest-common-substring over a 35,000-character source inside a Worker | medium | mitigate | Rolling-row implementation with a performance assertion in the test suite, so a long liveblog cannot exhaust the Worker's CPU budget |
| T-02-24 | Information Disclosure | Article text echoed into logs by the check | low | mitigate | Log lines carry flag codes and truncated evidence, not full source or summary bodies |
</threat_model>
