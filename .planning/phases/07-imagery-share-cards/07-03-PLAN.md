<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| D1 article/listing text → `<meta content>` | AI-generated titles and standfirsts become attribute values on ~60k static pages and ~62k archived pages |
| head tags → third-party scrapers | Platforms trust og:url/og:image to build previews |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering (XSS) | Base.astro meta/link rendering | high | mitigate | Values only through Astro `{...}` attributes (Astro entity-escapes `"` and `&`, so a value cannot leave its quoted attribute); builder returns raw strings (no double escaping); harness `injection` variant asserts quote/ampersand escaping, no new script element, and an exact decoded round-trip (test e) |
| T-07-09 | Spoofing | og:url | medium | mitigate | og:url is always the canonical href built from Astro.site (test c), never from the image origin or the request host |
| T-07-10 | Tampering | Build determinism (re-upload churn, 04-11a) | medium | mitigate | Builder module has no per-build values; harness double build asserts byte-identical heads (test f) |
| T-07-11 | Information Disclosure | Noindex pages advertising previews | low | accept | D-14 is the owner's explicit choice: a pasted link to a noindex page still previews; the pages are public already |
| T-07-SC | Tampering | npm/pip/cargo installs | low | accept | No package is installed in this plan |
</threat_model>
