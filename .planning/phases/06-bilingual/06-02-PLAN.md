<objective>
Make the request path language-aware before any Spanish page exists: the canonical-path builder,
the Worker's redirect decision and the R2 archive keys gain a validated `en | es` dimension, so an
archived `/es/...` article is served from its own R2 object and a non-canonical `/es` URL lands on
the `/es` canonical — never silently on English.

Purpose: research's load-bearing finding — the KV key, R2 key and canonical-path check are all
uuid-only today, so an archived `/es` request would 301 to English. This is the early, blocking
fix everything archive-tier for `/es` depends on (D-06 URL shape, D-13 no involuntary language
switch). Output: language-aware `article-url.ts`, `article-redirect.ts`, `archive-route.ts`,
`worker.ts`, tests, and the recorded key-scheme decision.
</objective>

<assumption_delta_decision>
Identity model for archive-tier storage once a second language shares each uuid.
- **Primary noun:** the *translation group* (English uuid = `translationGroupId`, Phase 3 D-04)
  for identity; a *page* is (translation group, language).
- **KV render manifest — `no-change` to the stored identity entry.** `manifest:<uuid>` already IS
  the translation-group identity record: category slug, stored slug and uuid are untranslated
  (D-02/D-06), so the Worker reads that ONE entry for both `/x` and `/es/x` (still exactly one KV
  read per request, ARCH-08) and derives the language from the validated path prefix. No Spanish
  manifest entries are written this phase (nothing would read them). 06-04 still makes
  `manifestKey(articleId, language)` language-aware (`es` → `manifest:<uuid>:es`) so a Spanish
  entry can never overwrite the English one if a later writer ever emits one.
- **R2 archive keys — `add-alongside`.** English keys stay `articles/<uuid>.html` /
  `tags/<slug>.html` (unprefixed = default language, exactly like the published URLs and
  `x-default → English`, D-06/D-08); Spanish keys are `es/articles/<uuid>.html` /
  `es/tags/<slug>.html`. Rejected `promote` (`en/articles/…` for everything): it would rewrite
  ~30,500 English R2 objects, the archive index and the Worker read path in one coordinated
  switch for zero reader-visible gain.
- **Accepted debt:** English is the implicit default in key names. A promote would be forced by a
  third language that is not a simple prefix mirror, or by English ceasing to be the default.
</assumption_delta_decision>
