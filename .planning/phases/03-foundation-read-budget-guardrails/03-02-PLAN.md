<objective>
Turn the guardrail from "a file that exists" into "a guard that is proven to fire on every
commit", and close the one gap the module-graph walk cannot see by construction: config.

Purpose: Phase 2's CONT-06 defect is the precedent this plan exists to prevent — **248 tests
passed while 253 production rows violated the requirement**, because a check existed but had
silently stopped gating. D-06 demands permanent negative fixtures for exactly that reason, and
03-RESEARCH.md's assumption A1 warns that Astro's resolved module ids may not match a naive
path glob, which would make the checker match zero entrypoints and green every build. A binding
added to `wrangler.jsonc` is invisible to a graph walk because a binding is not a graph edge;
that needs its own cheap, deterministic check.

Output: a fixture suite that fails the build on both a page-shaped and an island-shaped
violation, a clean control that proves the checker is not simply rejecting everything, and a
config guard wired into the test command.
</objective>
