<objective>
Put the tracer on a real, publicly reachable host and make that host un-indexable at the edge —
then prove both by response header rather than by inspection.

Purpose: OPS-02 is the one requirement in this phase that cannot be asserted from a build-time
test, because it depends on live zone configuration that lives outside version control. D-08
accepted that tradeoff deliberately, on the grounds that a zone rule holds even when the Worker
errors or a broken build ships — which a `_headers` file shipped with the build does not, since
static asset requests bypass the Worker entirely and `_headers` rules do not apply to
Worker-generated responses. The cost of that tradeoff is that the rule can be silently removed
by an unrelated zone edit, so the verification has to be a command someone runs on every deploy.

Output: `915tldr-v2` deployed to `dev.915tldr.com`, a Transform Rule scoped to that hostname,
a recorded definition that survives its deletion, and a one-command live check.
</objective>

|----------|-------------|
| public internet → Cloudflare edge | Every reader request crosses here. The Transform Rule is the only control on this boundary in this phase, and it applies to responses on their way back out regardless of which layer produced them. |

| Cloudflare zone config → version control | D-08 accepted that the rule lives outside git. That makes zone state a trust boundary with no diff and no review. |
