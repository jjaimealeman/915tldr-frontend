<objective>
Stand up the storage half of the archive tier: a private R2 bucket, a write credential scoped to
that one bucket, and a build-time Node client (`src/lib/server/r2-client.ts`) that the archive
sync (05-07) uses to upload pages. Proven by a live round trip, and kept out of the Worker bundle
by the existing D1/KV chokepoint guard.

Purpose: REND-07 needs somewhere to render archived pages once. The build has no live bindings, so
it writes through R2's S3-compatible API (the same "no binding at build time" situation D1 is
already in).

Output: `@aws-sdk/client-s3` installed after the legitimacy checkpoint, the bucket and its
credential (owner), `r2-client.ts`, a round-trip probe tool, unit tests, a build-gate fixture case.
</objective>
