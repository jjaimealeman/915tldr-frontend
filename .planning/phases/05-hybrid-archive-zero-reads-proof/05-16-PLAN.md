<objective>
Fix the zero-reads gate's measurement asymmetry (05-REVIEW CR-03). `comparableWindows()` aligns
the 7 baseline windows outward to 5-minute buckets, but the load window is passed raw into a query
filtered on bucket starts (`datetimeFiveMinutes_geq`/`_lt`), so the bucket holding the window's
start is always dropped. The recorded run summed 9 buckets against the baseline's 10 (≈10%
undercount); a default 3,000-request run would compare 1 bucket against 2-3 (50-67% bias toward
PASS). Align both sides identically, prove it with a unit test, and re-check the recorded verdict
with a real read-only re-query rather than the review's ×10/9 estimate.

SATISFIED (05-VERIFICATION.md) and is not re-planned; this plan touches its code only.
