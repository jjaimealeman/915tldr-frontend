<objective>
Make the static file count a build-enforced budget line and move archive-tier pages out of the
static output: after `astro build`, a partition step relocates every archive-tier article and tag
page into `dist/archive/` (with a plan the R2 sync uploads from), and a file-count gate fails the
build at 80,000 files, warns at 70,000, and publishes the count in `static-budget.json`.

Purpose: REND-09 (tags below 10 articles leave the static tier), REND-11 (count reported every
build, build fails at the 80,000 margin, D-13), and the render-once half of REND-07 (archived pages
are this build's own output, uploaded later by 05-07).

`archive-plan.json` format (contract shared with 05-04 and 05-07):
`{ version: 1, generatedAt, hotWindow, cutoffEpoch, counts: { hotArticles, archivedArticles, hotTags, archivedTags }, entries: [{ kind: 'article'|'tag', key: 'articles/<uuid>.html'|'tags/<slug>.html', path: '/<category>/<slug>-<uuid>'|'/tag/<slug>', sha256, bytes }] }`.

Output: `tools/partition-archive.mjs`, `tools/assert-file-count.mjs`, the new build script, updated
dist-based tests and the byte-identity regression.
</objective>
