<objective>
Replace the bootstrap age fallback with a hot window derived from real readers: query 30 days of
v1's per-URL human traffic on 915tldr.com live, keep only article and tag URL shapes, compute how
old articles are when people read them, and pick the smallest age window that covers 95% of human
article reads — capped so the static file budget survives Phase 6. Write it to
`src/lib/archive/hot-window.json` and document the method, evidence and re-run procedure.

Purpose: REND-10 ("derived from measured request traffic, not a fixed guess"), fully verifiable at
phase end per D-07b (retention measured at 31 days; the collector D-07a planned is dropped).

Output: `tools/derive-hot-window.mjs`, tests and fixture, the derived `hot-window.json`,
`docs/phase-05/hot-window-derivation.md`.
</objective>
