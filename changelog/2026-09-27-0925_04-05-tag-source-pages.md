## Issues Encountered

**[Rule 1 - Bug] A frontmatter-local `const TAG_SLUG_RE` was silently dropped by the bundler.**
`tag/[slug].astro` originally declared `const TAG_SLUG_RE = /^[a-z0-9-]+$/;` at the top level of
its own frontmatter, referenced only from `getStaticPaths()`. The build failed at static-path
generation with `ReferenceError: TAG_SLUG_RE is not defined` — inspecting the compiled chunk
(`dist/server/.prerender/chunks/_slug__*.mjs`) showed the declaration was simply absent from
output, while every other frontmatter symbol compiled correctly. This is the exact same bug class
already documented in `03-01-SUMMARY.md` (a frontmatter-local `slugify()` function dropped by
Astro 7.3.3's bundler under the same conditions — extracted to `src/lib/slug.ts` there). Fixed the
same way: moved `TAG_SLUG_RE` into `src/lib/article-url.ts` (the existing home for
`ARTICLE_SLUG_RE`/`CATEGORY_SLUG_RE`) and imported it normally. Confirmed fixed: a full
`pnpm run build` completed cleanly (59,888 pages, ~2m 6s), and the built tag-page count
(19,767) matches `.astro/tag-build-log.json`'s authoritative count exactly.
