## Why

Task 2 of the 01-01 gate plan: install the toolchain the owner approved at the Task 1 legitimacy checkpoint and prove WebKit runs on this machine before any mockup or test work depends on it. This machine's Arch Linux has ICU 78 only; Playwright's WebKit build targets Ubuntu shared libraries, so native launch was expected to be a real risk — the Docker fallback was planned in advance for exactly this case.

## Issues Encountered

- Native WebKit launch failed as anticipated (`browserType.launch:` with missing Ubuntu-targeted shared libraries — Arch's ICU 78 doesn't satisfy Playwright's expected ICU 74). This is not a bug; it is the documented, planned-for environment risk from 01-RESEARCH.md and the plan's own objective section.
- `npx playwright install` printed a "host system missing dependencies" warning (expected on Arch, non-Ubuntu). No dependency-install flag was used, per the plan (it would shell out to `apt-get`, which doesn't exist here).
- Docker fallback succeeded on first try: WebKit 26.6 launched inside the pinned image, image digest recorded in `design/.webkit-mode.json`.
